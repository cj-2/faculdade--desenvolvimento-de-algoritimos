# Conceito de Lógica aplicada a Programas

## Algoritimo

"Algorítimo é a descrição de uma sequencia de passos que deve ser seguida para a realização de uma tarefa." (ASCENCIO, 1999, p. 2)

### Etapas para o desenvolvimento de um Programa

- Análise
- Algoritimo
- Codificação

O programa é a codificação de um algoritimo em uma linguagem de programação.

## Técnicas para o Desenvolvimento de Algoritimos

Técnicas mais conhecidas:

- Descrição narrativa - Descreve o algorítimo na liguagem nativa, Ex: Português
- Fluxograma - Descrição feita por síbolos gráficos já definidos.
- Pseudocódigo ou Portugol - É desenvolvida com uma lingaguem de programção básica.
